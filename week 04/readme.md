Objective Develop control over layout by manipulating: 
● Box model (margin, padding, border) 
● Positioning (static, relative, absolute, fixed, sticky) 
● Float and clear 
The page must expose layout errors when concepts are misapplied.

Requirements

Task 01
1. Create a section containing three stacked boxes (div elements)  
2. Each box must include: 
○ A heading 
○ A paragraph 
3. Apply the following styles: 
○ padding → create internal spacing 
○ border → solid, clearly visible 
○ margin → space between boxes

Task 02
Task 
1. Create a container (div) with a visible border. 
2. Inside it, add: 
○ A paragraph 
○ A small label (e.g. “NEW”) 
3. Apply: 
○ position: relative → container 
○ position: absolute → label 
4. Position the label at the top-right corner of the container. 
Additional Requirements 
● Create a header with position: fixed 
● Create a navigation bar with position: sticky
