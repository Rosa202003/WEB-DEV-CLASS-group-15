Objective Of Week 4
Develop a dynamic web application that captures user input, processes data using JavaScript, and updates the webpage instantly using DOM manipulation without page reload.


Scenario
Create a Student Grade Calculator Web Application to help
lecturers compute and display grades based on student marks in real time.

Task Requirements
Part A: User Interface Design
Creating a structured and user-friendly interface using HTML and CSS.
Requirements:
● Page title: Student Grade Calculator

● Input field:
○ Type: number or text
○ id="scoreInput"

● Button:
○ Label: Calculate Grade
○ id="calcBtn"

● Results display section:
○ Use a container element (e.g., <div>)
○ id="results"


Styling Expectations:
● Proper spacing (margin, padding)
● Centered or well-aligned layout
● Borders and background colors
● Readable font and typography

Part B: Event Handling and Input Capture
Use JavaScript to:
● Attach a click event listener to the button (calcBtn)

● Retrieve the value entered in scoreInput
● Store the value in a variable for processing
Part C: Input Validation
Validate user input before processing:
● Ensure input is:
○ A number
○ Between 0 and 100
● If invalid:
○ Display an error message inside results
○ Do not proceed with grade calculation
Part D: Grade Calculation and DOM Manipulation
Use control statements (if-else) to compute grades:
Score Range Grade
70–100 A
60–69 B
50–59 C
40–49 D
Below 40 F
Output Requirements:
● Display:
○ Entered score
○ Calculated grade
● Update content dynamically inside results using DOM methods such as:
○ textContent or innerHTML
Part E: Reset Functionality
After displaying the result:
● Clear the input field (scoreInput)
● Allow immediate entry of a new score
● Maintain dynamic interaction without page reload
Expected Functional Behavior
1. User enters a score
2. Clicks Calculate Grade
3. System validates input
4. Grade is computed
5. Result is displayed instantly
6. Input resets for next use

CHALLENGES
linking javascript file to html file
pushing repository and retrieving it for correction
the working of the js script
